Is the Samsung Galaxy M12 worth buying?

What is good

  • Large 5000 mAh battery capacity
  • Smooth 90Hz display refresh rate
  • Includes a dedicated headphone jack
  • Capable 48MP main camera sensor

What is not

  • Very slow 15W charging speed
  • Limited software update support remaining
  • Dated Exynos 850 chipset performance

Buy it if Buy this phone if you need a basic, reliable device for simple daily tasks and prioritize having a headphone jack.

Skip it if Skip this phone if you want the latest software features, fast charging, or a device that will receive security updates for years to come.

Why we say that

You get a 6.5 inch PLS LCD display with a 90Hz refresh rate, which makes scrolling feel smooth for the price. The 5000 mAh battery is a reliable workhorse that should easily last through a full day of use. However, the Exynos 850 chipset is quite dated, and you will likely notice performance limitations if you try to run heavy applications.

Because the phone was released in 2021, you should expect little to no remaining software support, which is a significant concern for long-term security. While the 48MP main camera captures decent detail, the overall experience is hampered by the slow 15W charging speed. If you decide to purchase this, be aware that you are buying a device that has reached the end of its intended software lifecycle.
