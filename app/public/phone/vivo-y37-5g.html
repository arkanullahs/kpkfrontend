Does this phone have an official brand warranty in Bangladesh?

No official brand warranty is listed. Only gray import stock is available, which means you will receive a shop warranty. You should confirm the IMEI and BTRC status with the seller before buying.

How long will I get software updates for this phone?

This phone runs on Android 14. While upper models get 3 OS updates, budget models like this one typically receive 2 OS updates.

The phone has a large 5000 mAh battery for long use. However, the charging speed is only 15W, which is slow compared to newer standards.

The phone has a 13MP main camera for rear photos. For selfies, it uses a 5MP front camera.
