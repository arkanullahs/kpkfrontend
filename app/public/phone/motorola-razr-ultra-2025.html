This is a high end foldable that prioritizes raw power and screen quality.

What works well

  • Very bright 4500 nits peak display
  • Fast Snapdragon 8 Elite chipset
  • Clean software with low bloatware
  • High 165Hz refresh rate

Reported trade-offs

  • Historically weak OS update record
  • No official brand warranty available
  • Gray import status requires IMEI verification

Why we say that

It uses the Snapdragon 8 Elite chipset and a very bright 165Hz LTPO AMOLED display. You get a clean software experience with Hello UI and very little bloatware. However, you must be careful with the purchase in Bangladesh.

Only gray import stock is available. This means you get a shop warranty instead of a brand warranty. You need to verify the IMEI and BTRC status with the seller before paying.

Read full reasoning

Owners of previous models often complain about weak software update support. Motorola historically provides only 1 to 3 OS updates, which is low for a device at this price point.
